Experimental Protocol
---------------------
  Paradigm: imagery
  Number of classes: 2
  Class labels: left_hand, right_hand
  Trial duration: 4.0 s
  Trials per class: left_hand=60, right_hand=60
  Study design: Cued left- vs right-hand motor imagery on two separate days. Each session has four blocks of 30 trials (15 left, 15 right, random order) with 5 min breaks; each 7 s trial has a 1 s 'Ready' preparation (0.25 s beep), a 4 s task period showing a left- or right-handed rowing game animation with sound, then a 2 s rest. Released as one file per session without block boundaries.

  Stimulus modalities: visual, auditory
  Synchronicity: cue-based
